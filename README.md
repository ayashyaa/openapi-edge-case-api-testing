# Automated API Contract Testing System

Automated API contract testing tool that generates realistic boundary and edge-case payloads based on OpenAPI/Swagger specifications.

## 📂 Project Structure
* `config/` - System and test runner configurations
* `diagrams/` - System architecture diagrams 
* `docs/` - Academic documentation and pre-defense deliverables
* `src/` - Core source code (Parser, Generator, Runner, Reporter)
* `tests/` - Unit and integration tests
